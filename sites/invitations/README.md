# Wedding invitations

One folder per couple, one `index.html` inside it. Each file is self-contained
— artwork embedded, no build step, no dependencies — so it can be mailed,
opened from disk, or dropped on any static host.

The wording of every language lives in the `T` object near the bottom of the
file. See `skills/wedding-invitation/SKILL.md` for how to make a new one.
